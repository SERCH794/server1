1. PIPELINE DE AGREGACIÓN · ESENCIA

El pipeline de agregación en MongoDB es un framework de procesamiento de datos que fluye documentos a través de una secuencia de etapas (stages). Cada etapa transforma los documentos.

$match
➡
$group
➡
$project
➡
$lookup
db.collection.aggregate([ { $match: { status: "A" } }, { $group: { _id: "$city", total: { $sum: 1 } } } ])

Casos de uso: reportes, análisis, transformación de datos, joins entre colecciones.

3. MODELADO: EMBEDDED vs REFERENCES

EMBEDDED (UNO a POCOS)

Documentos anidados, alta atomicidad, rendimiento lectura. Ideal para relaciones UNO a POCOS.

Ventajas: una sola consulta, actualización atómica.
⚠️ Límite 16MB.

REFERENCES (UNO a MUCHOS)

Separación de colecciones, flexibilidad. Uso de $lookup.

Escalable, evita crecimiento excesivo.
⚠️ Múltiples consultas o $lookup.

4. PIPELINE COMPLETO (EXPLICACIÓN VISUAL)

db.pedidos.aggregate([
  { $match: { userId: ObjectId("123") } },
  { $lookup: { from: "users", localField: "userId", foreignField: "_id", as: "userInfo" } },
  { $unwind: "$userInfo" },
  { $project: { fecha: 1, total: 1, nombreUsuario: "$userInfo.name" } }
])
